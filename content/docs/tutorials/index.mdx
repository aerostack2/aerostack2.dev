Each tutorial builds something small, one step at a time, and explains what happens underneath.
They all start from the [Quickstart](/docs/getting-started/quickstart) project and the multirotor
simulator, so they run on any machine, including macOS through Pixi, and you don't need a drone.

Do the getting started ones in order. The module ones stand on their own once you've done those.

## Extending Aerostack2

These tutorials are about using Aerostack2. To extend it, with a controller plugin, a new drone or
a package of your own, see the guides in [Develop](/docs/develop).
