title: Roadmap
description: Where Aerostack2 is heading.
icon: Map
---

These are the directions Aerostack2 is moving in. None of them has a date, and
ideas are shaped on
[GitHub Discussions](https://github.com/aerostack2/aerostack2/discussions/categories/ideas),
so join in if one matters to you.

- **New ROS 2 distributions.** Keep up with each ROS 2 release while
  supporting the current LTS ones.
- **Windows support.** Build and run Aerostack2 on Windows, alongside Linux
  and macOS.
- **Easier installs.** Ready-built packages for each release, so most users
  never need to build from source.
- **Motion control.** A cleaner motion controller architecture, more
  controllers, and less code duplicated between the controller and the
  simulator.
- **State estimation.** More estimator plugins, and better fusion of sensor
  sources.
- **Trajectories.** More trajectory generators, and a common interface to pass
  trajectories between nodes.
- **Path planning.** Planning for fixed-wing aircraft, and a more capable path
  planning behavior.
- **Behavior trees.** A more modular behavior tree that is easier to extend.
- **Swarms.** Better tools for many drones flying and talking together.
- **Platforms.** Support for more aircraft, such as recent DJI drones.
- **Simulation.** More Gazebo models, worlds and sensors to test with before
  flying.
- **Tooling.** A command-line tool that is easier to extend and maintain.
